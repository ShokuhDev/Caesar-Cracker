# Caesar Cipher Terminal

A simple terminal-based Caesar Cipher program written in C++.  
This project allows users to encrypt text, decrypt text using a known key, and test all possible keys using brute force.

## Features
- Encrypt plain text with a Caesar Cipher key
- Decrypt cipher text with a selected key
- Brute-force all possible Caesar Cipher shifts
- Simple terminal interface
- Animated loading effects
- Hacker-style green console design

## Purpose
This project was created for learning and demonstrating how the Caesar Cipher works in C++ through a simple command-line application.
